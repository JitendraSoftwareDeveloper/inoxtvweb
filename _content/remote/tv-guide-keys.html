The TV guide gets its own key map because the same buttons need to mean different things there. OK opens a channel rather than showing an info panel; Left opens the groups panel rather than a channel list. Twenty keys are remappable, in Settings › Remote control › TV guide.

Up and Down are absent from the list on purpose: in a grid they move the selection, and that is not a behaviour anyone benefits from changing.

Three keys open the groups panel: Left, Long Menu and Guide, because that is the panel people reach for most, and because a remote missing one of the three still has another. If you never use groups, those are the first three keys worth spending on something else.

Yellow is the one to reassign first. Open group options is a menu the guide is going to have and does not have yet, so the key is swallowed and nothing happens. Return to current programs is the obvious replacement, for the reason given below.

Everything a guide key can be assigned to

  • Open channel — play the selected channel.
  • Show menu, Show groups, Open settings.
  • Open channel options — the menu described below.
  • Change favorite status — adds or removes the selected channel from favourites in one press.
  • Show program description, Search.
  • Scroll to next programs, Return to current programs — move the time axis forward, and jump back to now.
  • Page scroll channels up, Page scroll channels down — a screenful of channels at a time.
  • Go back, Return to player, Ignore.

Two entries in the list are not connected in this build: Open group options, as above, and Open in external player, which is locked and reports Available for premium users wherever it appears. Neither is worth a key.

Return to current programs is not on any key by default and is the one most worth adding. Scroll three days forward looking for something and you will want a single button that brings the grid back to now.

What the channel menu contains

Long OK and Green both open it, and so does a long press on a touch screen, the two gestures were kept the same on purpose. The panel is divided into three labelled parts, naming the programme, the channel and the group a row would act on, so it is always clear what you are about to change.

Five rows work:

EntryWhat it does
RecordRecords the selected programme. Needs a recordings folder set first, and says Set a recordings folder first if there is none.
Custom recordingOpens the booking panel: start date, start time, duration, repeat and a name.
Add to favorites / Remove from favoritesThe same thing Red does, from the menu.
SearchOpens the search overlay without closing the guide first.
SettingsOpens settings in place.

Hold a cell for a programme that has not started yet and the menu narrows: the rows about something on air disappear, leaving Custom recording to book the slot outright.

The rest of the panel: Watch from start, Block channel, Hide channel, Assign EPG, Channel options, the three Manage… rows, Reorder channels, Copy channels, Create group, Block group, Hide group and Group options; highlights and does nothing. They mark out the menu's eventual shape. A row that highlights and does nothing is a smaller surprise than a row that appears later in a menu you have already learned, which is why they are there rather than hidden.

The practical consequence: there is no channel blocking or channel hiding in this build at all, and no way to point one channel at a different guide entry. If a channel's listings are wrong, the answer is a source whose identifiers match your playlist: missing TV guide data covers how to get one.

Managing groups, which is not in this menu

Group editing lives in Settings › Playlists › Manage groups, and it is more capable than a remote menu would be: a visibility switch per group, Show all groups and Hide all groups, Groups sorting offering By order in playlist, By name and Manual, and Reorder groups once sorting is Manual.

Switching off the groups you will never watch is the fastest way to make a large playlist usable, and it changes the guide and the channel lists together. On a playlist with two hundred groups, hide all of them and switch six back on rather than working down the list.

How far the grid actually scrolls

Scroll to next programs stops where your guide data stops. If your source carries two days, pressing Right repeatedly will run out on the second evening, and that is the data rather than the key. Backwards, the limit is Past days to keep EPG in the guide settings, which decides how much history the app keeps rather than discards.

Worth knowing before you go looking for a setting that does not exist: nothing in this key map can extend the grid. That is a question for the source you point the guide at.

Restoring the defaults

Restore to defaults resets the guide's keys only. Your player map and your movies and shows map are untouched, because all three are stored separately.
