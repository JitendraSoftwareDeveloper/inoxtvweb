Installing InoxTV on Fire TV

Fire TV has no Play Store, so the television build is installed from a direct download. It takes about four minutes, and the only fiddly part is one setting Amazon moved.

Last updated 7 September 2026

Fire TV devices run Amazon's fork of Android with the Amazon Appstore instead of Google Play, so the television build of InoxTV is installed by downloading it directly. Amazon supports this (the setting for it ships in Fire TV's own menus), and the whole thing takes about four minutes.

Step 1: install Downloader

From the Fire TV home screen, search for Downloader and install it from the Amazon Appstore. It is a free browser and file-fetching app, published by AFTVnews, and it is the standard tool for this on Fire TV.

Install it before touching any settings. The permission screen in the next step lists apps that are already installed, so Downloader has to be there for you to grant it anything.

Step 2: allow Downloader to install apps

This is the step people get stuck on, because Amazon has moved it more than once. Go to Settings › My Fire TV › Developer options, then turn on Install unknown apps for Downloader.

Two variations you may hit:

  • No Developer options entry. Newer builds hide it. Go to Settings › My Fire TV › About, highlight your device name, and press Select seven times. A message confirms developer options are on, and the entry appears in the previous menu.
  • Apps from Unknown Sources instead. Older builds show a single global switch rather than a per‑app list. Turn it on, and turn it back off after installing if you would rather not leave it enabled.

The modern per‑app form is the better arrangement: you are permitting Downloader specifically, not everything on the device.

Step 3: enter the code

Open Downloader. The home screen has a URL box. Enter:

2910810

and choose Go. That short code resolves to the current InoxTV television build, and it saves you typing a long GitHub release URL with a remote control. If you would rather use the full address, it is https://github.com/jitendrasoftdev/inoxtv-release/releases/download/inoxtv/tv-release.apk.

The download runs with a progress bar. On a normal home connection it finishes in well under a minute.

Step 4: install, then clean up

When the download completes, Fire TV shows the installer with the app name and the permissions it requests. Choose Install, wait for it, then Open to launch InoxTV straight away or Done to go back to Downloader.

Downloader then offers to delete the downloaded file. Accept: the app is installed and the APK is just taking up space, which matters on a 8 GB Stick more than you would like.

You are done installing

InoxTV now opens from the Fire TV home screen, though it will sit under Your Apps & Channels rather than on the main row until you move it. The app has no channels yet: that comes next, and it comes from your own IPTV service.

Step 5: add a playlist

On first launch you will see the intro screen explaining that InoxTV supplies no channels of its own, with an Add Playlist button. What you enter there depends on what your provider gave you: which playlist type to choose covers the decision in two minutes, and your first hour with InoxTV takes the whole setup from there in order.

Updating later

Repeat step 3 with the same code. The new build installs over the existing one, and your playlists, favourites, groups, key assignments and settings are all preserved. Android treats it as an update rather than a new app, provided you do not uninstall first.

There is no automatic update on Fire TV, because that is a store function and there is no store involved. Checking every couple of months is reasonable; the release notes say whether anything you use has changed.

If something goes wrong

Downloader says the app cannot be installed. Almost always the permission from step 2. Check it is granted to Downloader specifically, not to another app.

The download fails or stalls. Retry once. If it fails again, check the Stick has a working connection by loading anything else, since Downloader gives the same message for a network problem as for a missing file.

Not enough storage. Fire TV Sticks fill up quickly. Uninstall something you do not use, or delete old downloads inside Downloader's own file list.

Video plays but there is no sound. Fire TV devices are particular about audio formats, and a channel using one your setup cannot handle plays silently rather than complaining. Switch Audio decoder to Software in Settings › Playback, which is the fix that works most often here, the hardware decoder on these sticks accepts more formats than it handles well. The setting applies to everything you play, so put it back if it makes no difference.

The app installs but the remote does nothing useful. The Fire TV remote is missing several buttons a full Android TV remote has. Every key in InoxTV is reassignable, so the fix is to map what you need onto the buttons you actually have, the player key reference lists the defaults and every action available.

Questions people ask

What is the Downloader code for InoxTV?
2910810. Enter it on the Downloader home screen and it fetches the current Android TV build.
Why is InoxTV not in the Amazon Appstore?
Fire TV runs a fork of Android with its own store, and the app is published on Google Play. The direct download is the supported route on Fire TV, which is why the Downloader code exists.
Is sideloading safe on a Fire TV Stick?
Installing from an unknown source means you are trusting the source rather than a store's review. Amazon's own Developer options exist for it, and the permission is granted per app rather than globally. Turn it back off after installing if you prefer.
How do I update the app later?
Repeat the Downloader step with the same code. The new version installs over the old one and your playlists, favourites and settings are kept. This is an update, not a fresh install.
Which Fire TV devices does it work on?
Fire TV Stick, Fire TV Stick 4K, 4K Max, Fire TV Cube and Fire TV built into televisions. The oldest first-generation Stick has too little memory to be comfortable with a large playlist.
