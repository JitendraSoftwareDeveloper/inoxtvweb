Installing InoxTV on Android TV

Two routes, and it is worth trying the store one first. If Play says the app is not available for your device, that is a hardware filter rather than a missing app, and the direct download works anyway.

Last updated 7 September 2026

The television build of InoxTV is in.inoxtv.tv. It is a separate interface from the phone build rather than the same layout stretched, which is why installing the right one matters on a device you drive with a remote.

The Play Store route

Open the Google Play Store on the television, search for InoxTV, and install it. On a certified Android TV or Google TV device that is all there is to it, and updates arrive automatically afterwards.

Searching by voice usually works better than the on‑screen keyboard here. If the results show the phone build rather than the television one, you are looking at a store that has decided your device is not a television — which brings us to the other route.

Why Play sometimes hides it

Play decides what to show based on what the device declares about itself. A television build is published against the leanback feature that marks a device as remote‑driven, and plenty of inexpensive Android TV boxes either omit that declaration or report themselves as phones outright.

When that happens Play says the app is not available for your device. That is a filter, not a verdict on compatibility: the app runs on those boxes exactly as it does elsewhere. Install it directly instead.

The direct download route

  1. Install a file-fetching app

    Downloader from Play is the usual choice and works on Android TV as well as Fire TV. Any app that can fetch a URL and hand the file to the installer will do.

  2. Allow it to install apps

    The setting lives in different places depending on the manufacturer. Look for Settings › Apps › Security & restrictions › Unknown sources, or Settings › Device Preferences › Security & restrictions. Grant it to the app you installed in step 1, not globally if the choice is offered.

  3. Fetch the build

    In Downloader, enter the code 2910810. The full address, if you prefer it, is https://github.com/jitendrasoftdev/inoxtv-release/releases/download/inoxtv/tv-release.apk — the code exists because typing that with a D‑pad is unpleasant.

  4. Install and tidy up

    Choose Install when the download finishes, then Open. Let Downloader delete the downloaded file afterwards; a TV box with 8 GB of storage does not have room to spare.

Which route you used matters later

Apps installed from Play update themselves. Apps installed directly do not — you repeat the download when a new version comes out. Mixing the two is not possible: switching an existing install from one route to the other means uninstalling first, which discards your playlists unless you have taken a backup.

First run

InoxTV opens on an intro screen stating that it provides no sources of TV channels, with an Add Playlist button. That is the expected state on a fresh install: the app is a player and the channels come from your own IPTV service.

What to enter depends on what your provider issued you. Which playlist type to choose settles that in a couple of minutes, and your first hour with InoxTV runs through the whole setup in the order that avoids doubling back.

If the install itself fails

Three failures account for nearly all of them, and Android's wording for each is unhelpfully similar.

App not installed. Almost always a signature clash: a copy of InoxTV is already on the device from a different source, and Android will not replace one with the other. Uninstall the existing copy first — and take a backup before you do, because uninstalling takes your playlists with it.

The install screen never appears. The permission from step 2 was granted to the wrong app, or not at all. Go back to the security settings and check the entry for the app you are downloading with, rather than a global switch elsewhere.

Not enough storage. Common on 8 GB boxes and Sticks. Downloading needs room for the file and then room for the installed app at the same time, so clearing a little space before you start is easier than clearing it halfway through. Deleting the downloaded file afterwards gets that half back.

Both builds can sit on one device if you want them to — they are separate packages, so a TV box can run the television build and a tablet build side by side without either interfering with the other.

Before you go further: the remote

Remotes shipped with TV boxes vary enormously in which buttons they have. InoxTV lets you reassign every key in the player, the channel list and the guide, so a remote missing a colour‑button row or a dedicated guide button is not a problem — it just needs mapping once. The player key reference lists every default and every action you can move.

Doing that early is worth it. Discovering after a month that the button you keep pressing by accident could have been the one you wanted is a common regret.

Questions people ask

Why does the Play Store say the app is not available for my device?
Play filters by declared hardware. Some TV boxes report themselves as phones, or omit the leanback feature that marks a device as a television, and the television build is then hidden. The app runs perfectly well on those boxes; the direct download bypasses the filter.
Should I install the TV build or the mobile build on a TV box?
The television build. It is a different interface designed for a D-pad, not the phone layout scaled up. The mobile build will install on a TV box but expects touch input, which makes several screens awkward to operate.
Do I need a Google account on the television?
Only for the Play route. The direct download needs no account at all, which is useful on a box where you would rather not sign in.
Will a direct install still update from Play later?
No. A build installed by direct download is updated by downloading the newer build the same way. Installing from Play over it is not possible without uninstalling first, which loses your playlists unless you take a backup.
